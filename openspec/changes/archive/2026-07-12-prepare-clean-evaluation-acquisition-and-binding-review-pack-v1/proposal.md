## Why

The archived clean-evaluation boundary is honestly blocked at S0 because no independent metadata-only acquisition source or reviewed 29-binding packet exists. The repository has strict execution validators and test-only valid fixtures, but it lacks a public-safe, operator-facing intake and review pack that external providers and reviewers can complete without mistaking examples or placeholders for executable inputs.

## What Changes

- Add a deterministic, public-safe, preparation-only review pack containing a canonical 29-item binding catalog, one non-executable candidate envelope whose four nested drafts also use non-executable draft schemas/field sets, strict structural schemas for those sections, and acquisition-ancestry/reviewer-independence checklists.
- Add a non-mutating envelope linter and gap report that distinguishes structural completeness from independent review and execution eligibility, never accepts or exports the four raw execution components, never opens a source frame or lockbox rows, never freezes a protocol, and never creates or modifies the clean-boundary private root.
- Require committed templates to carry explicit template-only markers and non-supplied sentinels that fail closed when passed to the existing execution validator; test fixtures remain tests and never become project evidence or defaults.
- Define a conservative candidate handoff state that may report only `STRUCTURALLY_COMPLETE_REVIEW_REQUIRED`; self-reported labels, hashes, and `APPROVED` fields do not prove external authority or human acceptance, so `human_acceptance_status=NOT_RECORDED`, `freeze_authorized=false`, and `next_phase_eligible=false` remain fixed in this change.
- Preserve two separate truth surfaces: the archived execution attempt remains `evidence_status=BLOCKED`, `decision=CLEAN_EVALUATION_BOUNDARY_MATERIALIZATION_BLOCKED`, `current_readiness_state=DESIGN_ONLY`, 0/29 bound, source unavailable, protocol not frozen, and population not materialized; the new operator pack is independently classified `evidence_status=DESIGN_ONLY` and `phase_status=PREPARATION_ONLY`. Both keep `execution_readiness=false`.
- Define a fixed-path hybrid publication contract under a trusted, exclusive, cooperative same-EUID review-writer boundary: supported absent-path no-replace creation with `0700` staging promoted as verified `0755`; exact-existing verified no-op and changed/unsafe rejection, each with no namespace, content, or capability-issued metadata mutation; observation-first handling after uncertain syscall outcomes; and verified-owned `0700` recovery state that blocks current evidence until separate manual disposition. Filesystem-managed access-time changes caused solely by descriptor reads are the only exclusion from that no-mutation contract.
- Do not add or strengthen any threat, recovery, cleanup, rollback, update, lifecycle, or authorization guarantee for the legacy public-evidence writer; preserve only its existing observable compatibility behavior through regression tests, with a formal legacy threat model deferred to a separate change.
- Do not implement a compiler/decoder, change prompts, decoding, the existing runtime Browser Task Contract schema, evaluator, or runtime policy, author evaluation rows, access gold/outcomes/lockbox rows, reuse public/challenge/remediation/prediction/lockbox data as the source, run training or prediction, use A100, start generic chat fine-tuning, skill routing, GUI action-policy learning, or first-phase GRPO, publish the full local corpus, release a checkpoint, or claim model, executable, production, safety, natural-ASR, or live-browser improvement.

## Capabilities

### New Capabilities

- `clean-evaluation-acquisition-and-binding-review-pack`: Defines the preparation-only templates, schemas, responsibility/evidence matrix, lint states, privacy rules, and separately authorized handoff for obtaining independently reviewed clean-boundary inputs without advancing the execution lifecycle.

### Modified Capabilities

None. The existing `clean-compiler-model-evaluation-boundary` capability remains the sole authority for binding, protocol freeze, materialization, sealing, and lifecycle advancement.

## Impact

- Adds public, non-executable review-pack artifacts and focused preparation-only generation/lint interfaces.
- Adds conformance tests for exact 29-field parity, deterministic output, strict schemas, placeholder rejection, unchanged-envelope rejection by the existing freeze path, zero source/lockbox-row reads, sanitized diagnostics, publication preconditions, exact-existing verification, atomic no-replace competition, mechanical recovery classification/current gates, supported-platform behavior, and zero protocol/private-artifact mutation.
- Adds bounded `voice2task-data` entry points for generating and linting one non-executable envelope; existing clean-boundary execution commands and success/failure semantics remain unchanged.
- Leaves all real provider identities, authority hashes, numeric/statistical choices, source-frame digest, and reviewer approvals to externally supplied, separately reviewed inputs in a later authorized phase.
