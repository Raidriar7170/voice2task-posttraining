Compiler / System 分区

compiler_system_evaluation

未来以同一条冻结 raw record 为观察单位，两臂接收 byte-identical 模型输出与 provenance；primary 为完整固定分母上的 compiled-V1 strict exact。

Model Learning 分区

model_learning_evaluation

未来以 preregistered semantic family 为观察单位，只允许一个命名训练干预，并保持 data、prompt、decoder、compiler policy、evaluator、budget 与 eligible population 配对。

  • 至少 3 个冻结 paired seeds，failed/missing seeds 不得删除或选择性重跑。
  • primary 只覆盖 model-authored fields。
  • compiler-filled fields 不得包装成模型学习提升。

为什么选择方案 A

一次 acquisition/lineage 设计减少重复采集与标注成本；在 acquisition 前冻结 family key、算法、seed、strata、allocation 与最小规模，materialization 时再把 family registry 按冻结规则分配，并在 row authoring、gold 或 outcome access 前封存。这样 compiler 可以先开箱而不提前花掉 model-learning 证据。共享 sequential partition 会造成证据污染；两套完全独立 acquisition 又超出当前最小阶段。
